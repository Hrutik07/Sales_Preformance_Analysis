# Sales_Preformance_Analysis

Power BI Sales Performance Dashboard analyzing revenue, profit, customers, products, categories, regions, and profit margins with interactive filters and KPI metrics.

## Project Overview

This project is a Power BI Sales Performance Dashboard created to analyze sales, revenue, profit, customers, products, categories, regions, and monthly performance.

The dashboard converts raw sales data into an interactive and easy-to-understand business report using Power BI, Power Query, and DAX.

## Project Objectives

The main objectives of this project are:

- Analyze overall revenue and profit performance
- Calculate profit margin
- Analyze monthly revenue trends
- Compare revenue across regions
- Compare revenue across categories
- Identify top customers by revenue
- Identify top products by revenue
- Analyze product-level profit margins
- Provide interactive filtering through slicers
- Present key business metrics through KPI cards

## DAX Measures

The following DAX measures were created for the dashboard.

### Total Revenue

```DAX
Total Revenue = SUM('Sales Data - Raw_Data'[Revenue])
```

### Total Profit

```DAX
Total Profit = SUM('Sales Data - Raw_Data'[Profit])
```

### Profit Margin %

```DAX
Profit Margin % =
DIVIDE(
    [Total Profit],
    [Total Revenue],
    0
)
```

### Average Order Value

```DAX
Average Order Value =
DIVIDE(
    [Total Revenue],
    [Total Orders],
    0
)
```

### Average Profit per Order

```DAX
Average Profit per Order =
DIVIDE(
    [Total Profit],
    [Total Orders],
    0
)
```
